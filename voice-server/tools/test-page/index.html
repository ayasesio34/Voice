实时统计（这是验收 M3 的关键面板）

方向参与者类型编码分辨率 帧率码率丢包
—
看 方向=发送 / 类型=屏幕 那一行：
· 分辨率要是 1920×1080，帧率要接近你选的档位（60 或 30）
· 码率要稳定在设定值的 ±15% 以内
· 如果帧率明显低于档位 → 编码器扛不住，换 H.264 或降档
· 如果分辨率被自动降到 1280×720 → maintain-resolution 没生效，文字会糊
· ⚠️ 屏幕内容不动的时候，帧率和码率会掉到 0 —— 这是正常的。 屏幕捕获只在画面变化时才产生帧。所以要测性能，请一边共享一边持续动鼠标 / 滚页面 / 放视频， 盯着静止的桌面只会看到 0。
